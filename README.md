# Kepokkaw Cashier

Offline cashier and sales tracker for one Kepokkaw keropok lekor stall. It runs as a home-screen web app on iPad or iPhone.

All sales, expenses and stock are stored on the device only. Nothing is sent anywhere. Use **Settings → Back up everything** daily.

**Install:** open the site in Safari, tap Share, then **Add to Home Screen**. After the first open it works with no internet.

**Update:** change the files, bump `VERSION` in `sw.js`, push. Devices pick up the new version the next time the app is opened online.

Fonts: Barlow and Barlow Condensed, SIL Open Font License (see `fonts/OFL.txt`).
